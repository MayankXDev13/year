Drizzle ORM · SQLite
Table Purpose Key Columns & Constraints
user, session, account, verification Better Auth core tables Managed by Better Auth Drizzle adapter; user.id referenced by all board tables with ON DELETE CASCADE.
plans Multi-day & single-day board plans id, userId, title, startDate, endDate, category, status (planned|done|missed), notes
habits User daily/weekly habits id, userId, name, color, weeklyTarget (1–7), isLabs, dailyMinutesTarget

lab_entries Focus / Labs logged minutes id, userId, dateKey, topic, minutes
quarter_goals Up to 5 goals per quarter id, userId, year, quarter (1–4), title, done
week_meta Week focus & notes userId, weekKey (e.g. 2026-W47), focus, notes · composite PK (userId, weekKey)
user_preferences Board UI settings userId (PK), ownerName, density, view, theme, hiddenCategories (JSON)

4 TanStack Query, Better Auth & Error Handling

Zero Silent Failures

TanStack Query + Native fetch

  • Typed fetch wrapper (apiFetch<T>) with credentials: 'include', JSON parsing, and typed ApiError(status, code, message).
  • Query keys: ['board', year], ['session'] with smart staleTime and automatic invalidation.
  • Optimistic mutations for toggling habits, cycling plan status, and editing week focus — rolls back cleanly on network/API failure with error toast.
  • Dual mode: Guests get instant local Sample Year; signed-in users seamlessly read/write Cloudflare D1.

Better Auth & Error / 404 Handling

  • Better Auth error redirect: Configured with onAPIError: { errorURL: `${WEB_URL}/auth/error` } so OAuth/callback/session errors redirect cleanly to /auth/error?error=....
  • /auth/error page: Translates Better Auth error codes (INVALID_CREDENTIALS, SESSION_EXPIRED, STATE_MISMATCH, ACCESS_DENIED, etc.) into clear user messages with Sign-in & Home recovery buttons.
  • 404 Not Found page: Catch-all * route in web app + JSON 404 handler in Hono API + Cloudflare Pages _redirects SPA fallback.
  • Global Error Boundary: Catches unexpected React render crashes with reset/reload recovery, plus Hono app.onError returning clean JSON without leaking stack traces.

5 CI/CD Pipeline (Cloudflare Pages First → D1 → Worker)

GitHub Actions
STAGE 01
Verify & Build

pnpm install --frozen-lockfile, turbo lint typecheck build across all apps & packages.

STAGE 02
Deploy CF Pages

Build apps/web with VITE_API_URL and deploy to Cloudflare Pages first via cloudflare/wrangler-action.

STAGE 03
D1 Migrations

Apply pending SQL migrations to remote D1 via wrangler d1 migrations apply --remote.

STAGE 04
Deploy CF Worker

Deploy apps/api Worker and run post-deploy /api/health smoke check (fails workflow if unhealthy).

Required GitHub Secrets: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID, BETTER_AUTH_SECRET, VITE_API_URL, WEB_URL.
