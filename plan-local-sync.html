Local-First Guest Mode & Sync-on-Login Plan

Full guest interactivity in localStorage · Safe local clear · Automatic & conflict-safe merge into Cloudflare D1 on login

1 User Lifecycle Flow

Zero Friction
STEP 01 · GUEST

Use Without Login

Add habits, check-ins, plans, goals & notes directly in localStorage. Sets hasLocalEdits=true on first real edit.

STEP 02 · RESET

Clear Local Board

Guest-only Clear local data option in Board Settings (with confirmation) to wipe habits/plans and start blank.

STEP 03 · LOGIN

Sign In (GitHub/Google)

Detects hasLocalEdits. Auto-imports into empty D1 accounts, or prompts Merge vs Keep Cloud if cloud data exists.

STEP 04 · SYNCED

Cloud D1 Mode

All changes persist directly to Cloudflare D1 via TanStack Query. Signing out clears query cache cleanly.

2 Technical Design

Shared + API + Web

Client Local Storage Guard

  • Track year-board-local-dirty in localStorage so untouched Sample Year data is never accidentally imported into a real user account.
  • Any guest mutation (create/edit/archive/delete habit, toggle check-in, add plan/goal, edit week focus/notes, or clear board) sets hasLocalEdits = true.
  • Guest-only Clear local data button in Board Settings resets to an empty board with a quick inline confirm step.

POST /api/board/import (D1)

  • Validated with importBoardSchema in packages/shared.
  • Remaps local habit IDs to fresh UUIDs, deduplicates by habit name if already present in D1, and imports all habitCheckins with ON CONFLICT DO NOTHING (past & today only).
  • Imports local plans, quarterGoals (respecting max 5/quarter), and merges weekMeta without clobbering existing cloud notes.

3 Login Sync Scenarios

Conflict-Safe
Local Edits? Cloud D1 Account Behavior on Sign-In
false (untouched sample) Empty or Existing Loads cloud D1 board directly. Never imports fake sample data.
true (guest made edits) Empty (0 habits & 0 plans) Auto-calls POST /api/board/import, clears dirty flag, shows "Synced your local board to your account" toast.
true (guest made edits) Existing cloud data Opens Sync Local Changes Modal: Merge local into account or Keep cloud data only.
