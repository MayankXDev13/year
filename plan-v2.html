2 Habit Archive/Unarchive & No Future Check-ins

D1 + API + UI

Archive & Unarchive Habits

  • Add archived boolean column to D1 habits table via migration 0001_archive_habits.sql.
  • Archive button in Habit edit modal / menu: moves completed or paused habits out of the active sidebar while preserving all historical check-ins & streaks.
  • Collapsible Archived habits drawer/section in Sidebar with one-click Unarchive and Eye overlay to inspect past check-ins on the year board.
  • Archived habits do not block current/future Perfect Weeks.

Past & Today Only Rule

  • Users can check/uncheck today and any past date (e.g. catching up on a missed Running log from yesterday).
  • Future dates are strictly blocked (e.g. cannot tick Sunday's habit on Saturday).
  • Enforced in UI (future cells disabled with tooltip "Can't log future days") AND in API (POST /api/habits/:id/toggle rejects dateKey > today with HTTP 400).
